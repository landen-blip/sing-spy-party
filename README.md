# 🎤 声份谜局 · 唱歌谁是卧底

一个真正支持 **2–10 台手机或电脑实时联机** 的歌曲版「谁是卧底」网页应用。纯 Node.js 原生 HTTP + Server-Sent Events，没有 npm 第三方依赖。

## 功能

- 房主选择 2–10 人的房间上限，创建 5 位房间号，其他玩家通过邀请链接或房间号加入。**至少 2 人即可提前开局，不必等到满员**。
- 每局从内置 30 组相近情景中随机抽取一组，**3–10 人局中，除 1 名卧底收到另一情景外，其余玩家收到相同情景**；卧底位置随机生成。
- 每个玩家只收到自己的秘密情景；可点开查看、立即隐藏。其他人的情景绝不下发给客户端。
- **3–10 人经典卧底局**：大家线下轮流唱歌，房主开启投票；每位存活玩家独立投票，系统即时同步人数并自动统计。**不能投自己**。
- **2 人双人局**：两个人各拿到不同的相近情景，轮流唱歌后，分别从 4 个选项猜对方情景；猜对者获胜，双方都猜对或都猜错则平手，避免两人互投永远平票。
- 经典卧底局中，平票自动进入重投，只能在并列最高票选项中选择；投错淘汰平民并进入下一轮；抓到卧底则平民获胜；仅剩 2 人且卧底存活则卧底获胜。
- **默认不公布卧底身份或双方情景**。游戏结束后，只有房主主动点击「揭晓身份」才会公布。
- 一键开启下一局，重新随机发题、重新随机卧底；同一个房间可继续玩。
- 手机横竖屏适配，页面刷新后凭本机 localStorage 自动恢复游戏身份，原生 SSE 断线重连。

## 在电脑上启动（同 Wi-Fi 的手机也能进入）

要求 Node.js 18+。

```bash
npm start
```

电脑浏览器打开：`http://localhost:3000`。同一 Wi-Fi 下，手机用 `http://电脑局域网IP:3000` 打开（**不是** `localhost`）。Mac 查 IP：`ipconfig getifaddr en0`。防火墙需允许 Node.js 的入站连接。

## 让不在同一 Wi-Fi 的人也能玩（公网部署）

建议部署成一个 Node Web Service。比如 Render：

1. 将解压后的全部文件放到一个 GitHub 仓库中。
2. 在 Render 创建 **Web Service**，连接这个 GitHub 仓库；或用仓库内 `render.yaml` 创建 Blueprint。
3. Runtime 选 Node，Build Command 输入 `npm install`，Start Command 输入 `npm start`，部署完成得到 HTTPS 地址。
4. 打开 Render 给的 HTTPS 地址建房，复制邀请链接给其他人即可。

**注意**：GitHub Pages / 普通静态文件托管不行，因为多人联机需要常驻 Node 服务端。Render 免费服务可能休眠，且重启会清空内存中的房间；如希望游戏跨重启存档，可后续接入 Redis/数据库。服务内存中的房间默认 12 小时无活动过期。本项目没有账户系统，不保存个人敏感资料。

## 项目结构

- `server.js`：房间、发题、授权、实时同步、投票与获胜判定。
- `scenarios.json`：可自由增加/修改情景对。一组中 `common` 是平民，`spy` 是卧底情景。
- `public/`：手机优先的响应式界面（HTML/CSS/JS）。
- `render.yaml`：Render 一键部署配置。
- `test/`：Node 内置测试，`npm test`。

## 注意

这是朋友聚会用的小应用，并非抵御恶意黑客的企业级服务。隐私依靠服务器的独立会话令牌；切勿把自己的页面、令牌发给其他玩家。为减少剧透风险，普通游戏流程不提供任何可以查看其他玩家情景的接口。房主没有额外看词权限。2 人互猜模式只有在房主主动揭晓后才会向双方显示真实情景。

### macOS 便捷启动

装好 Node.js 后，可以直接双击 `start-mac.command`。它会打印电脑访问地址和同 Wi-Fi 手机访问地址。首次打开可能需要右键选择「打开」，并允许终端 / Node.js 网络访问。关闭终端即关闭本机服务。
